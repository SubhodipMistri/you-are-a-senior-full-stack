# Playspire

Premium, responsive esports tournament platform built with Next.js 15, TypeScript, Tailwind CSS, Framer Motion, and Prisma.

## Start locally

1. Copy `.env.example` to `.env` and configure PostgreSQL and provider credentials.
2. Run `pnpm install`, then `pnpm prisma:generate` and `pnpm prisma:migrate`.
3. Launch with `pnpm dev`.

The project includes public discovery pages, tournament registration, player dashboard, profile, wallet, teams, leaderboards, reward shop, typed REST foundations, a normalized Prisma schema, SEO routes, responsive UI, and security headers.
